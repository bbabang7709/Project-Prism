# 게임 규칙과 방

물체의 동작, 두 높이의 빛, 내려다볼 때 물체를 구분하는 법, 방 16개의 내용입니다.

[← README로 돌아가기](../README.md)

| 물체 | 동작 |
|---|---|
| **광원** | 흰빛을 쏩니다(낮은 빛). |
| **프리즘** | 흰빛을 빨강(왼쪽 45도), 초록(직진), 파랑(오른쪽 45도)으로 나눕니다. |
| **거울** | 빛을 반사합니다. 22.5도씩 8단계로 돌릴 수 있습니다. |
| **반투명 거울** | 빛을 반은 반사하고 반은 통과시킵니다. |
| **파랑 필터** | 파랑만 통과시킵니다. 색유리 상자라서 어느 방향에서 온 빛이든 걸러집니다. |
| **빨강 필터** | 빨강만 통과시킵니다. |
| **유리 블록** | 비스듬히 들어온 빛을 굴절시킵니다(굴절률 1.5). 임계각을 넘으면 전반사합니다. |
| **발판과 창살** | 방의 발판이 모두 눌려 있고 감지기가 모두 켜져 있는 동안 창살이 열립니다. 발판은 사람이 서 있거나 물체가 놓여 있으면 눌립니다(눌리면 초록색). 닫힌 창살은 빛과 사람을 모두 막습니다. |
| **수정** | 빨강, 초록, 파랑, 노랑, 청록, 자홍, 흰색이 있습니다. 섞인 색은 여러 빛이 함께 닿아야 켜집니다: 노랑 = 빨강 + 초록, 청록 = 초록 + 파랑, 자홍 = 빨강 + 파랑, 흰색 = 빨강 + 초록 + 파랑(흰빛 그대로도 됨). 원하지 않는 색이 섞이면 켜지지 않습니다. |
| **감지기** | 어떤 색이든 빛을 받으면 렌즈가 청록색으로 켜집니다. 방의 감지기가 모두 켜져 있는 동안 창살이 열립니다(발판이 있으면 발판도 모두 눌려야 함). 빛을 받은 감지기는 빛을 더 보내지 않습니다. |
| **순간이동 고리** | 방에 두 개가 한 쌍으로 있습니다. 한쪽 고리에 들어간 빛은 다른 고리의 같은 자리에서 같은 방향으로 나옵니다. 벽 너머로 빛을 보낼 수 있습니다. |
| **상자** | 들고 다닐 수 있는 나무 상자입니다. 빛을 막고, 발판 위에 두면 발판을 누릅니다. 원하지 않는 빛을 막을 때 씁니다. |
| **연결 번호** | 발판, 감지기, 창살에는 연결 번호(색)가 있습니다. 창살은 **같은 색**의 발판이 모두 눌리고 감지기가 모두 켜져 있는 동안 열립니다. 기본은 청록(번호 0)이고, 주황·분홍·하늘이 있습니다. 나뉜 방에서는 내 방의 발판이 상대 방의 창살을 엽니다. |
| **전달 창구** | 방을 나누는 벽에 뚫린 낮은 창구입니다(노란 빗금 테두리의 나무 판). 사람은 지나갈 수 없지만, 물체를 올려놓으면 반대편 사람이 집어 갈 수 있습니다. 낮은 빛은 지나가고 높은 빛은 막힙니다. 창구 너머의 물체나 바닥은 겨눌 수 없습니다. |
| **낮은 벽** | 무릎 높이의 벽입니다. 사람과 낮은 빛을 막지만, 높은 빛은 그 위로 지나갑니다. 위가 트여 있어 너머가 보입니다. |
| **빛 승강기** | 들고 다닐 수 있는 유리관입니다. 지나가는 빛을 같은 방향 그대로 다른 높이로 옮깁니다(낮은 빛 → 높은 빛, 높은 빛 → 낮은 빛). 빛이 지나가면 관 속이 그 빛의 색으로 빛납니다. |

## 두 높이의 빛

빛은 바닥에서 0.55칸 높이(**낮은 빛**)나 1.55칸 높이(**높은 빛**)로 지나갑니다. 광원은 늘 낮은 빛을 쏘고, 빛 승강기만 높이를 바꿉니다.

| | 낮은 빛 | 높은 빛 |
|---|---|---|
| 벽, 기둥, 문, 창살 | 막힘 | 막힘 |
| 낮은 벽 | 막힘 | **위로 지나감** |
| 유리 블록 | 굴절 | 위로 지나감 |
| 전달 창구 | 지나감 | 막힘 |
| 사람의 몸 | 가려짐 | 머리 위로 지나감 |
| 물체 (거울, 수정, 필터 등) | 반응함 | **위로 지나감** (빛 승강기만 반응) |

그래서 높은 빛은 "벽과 물체를 건너뛰어 멀리 보내는 길"로 쓰고, 다시 승강기로 내려야 거울로 꺾거나 수정을 켤 수 있습니다.

## 물체 구분법

위에서 내려다볼 때는 **받침 윗면의 고리 색**으로 물체를 구분합니다. 받침 자체가 구리색이면 들 수 있는 물체, 어두운 회색이면 고정된 물체입니다.

| 고리 색 | 물체 |
|---|---|
| 노랑 | 광원 |
| 흰색 | 거울(은색 판), 프리즘(무지개빛 세모기둥) |
| 하늘색 | 반투명 거울, 빛 승강기(높은 유리관) |
| 필터 색 | 필터 (색유리 상자) |
| 청록 | 감지기 (꺼져 있으면 옅게, 켜지면 렌즈까지 밝게) |
| 보라 | 순간이동 고리 (가로·세로 고리와 빛나는 구슬) |
| 갈색 | 상자 (구리 띠를 두른 나무 상자) |
| 수정 색 | 수정 (꺼져 있으면 옅게, 켜지면 밝게) |

## 방

**방의 수정이 모두 켜지면 문이 열립니다.** 열린 문으로 걸어 들어가면 다음 방으로 넘어가고, 마지막 방의 문을 지나면 게임을 마칩니다. 방마다 정답 각도는 `./prism --check --solve --level n`으로 확인할 수 있습니다.

방은 **장치가 하나씩 늘어나는 순서**로 놓여 있습니다. 어떤 장치가 처음 나오는 방에 들어가면, 그 장치가 무엇을 하는지 짧은 카드가 먼저 뜹니다.

| 방 | 이름 | 처음 나오는 것 | 내용 |
|---|---|---|---|
| 1 | 첫걸음 (튜토리얼) | 광원, 거울, 흰 수정 | 걷기 → 들기 → 내려놓기 → 돌리기 → 내려다보기 → 수정 켜기 → 나가기를 카드가 한 단계씩 안내합니다. 앞의 거울을 빛길에 옮겨 돌리면 됩니다 |
| 2 | 갈라진 세 빛 | 프리즘 | 프리즘이 나눈 세 빛을 각자의 수정으로. 비스듬한 빛은 거울을 홀수 각도(22.5도)로 돌려야 곧게 꺾임 |
| 3 | 두 빛의 만남 | 반투명 거울, 필터, 노랑 수정 | 반투명 거울과 빨강 필터, 프리즘으로 빨강과 초록을 노랑 수정에서 만나게 하기 |
| 4 | 빛의 신전 | 유리 블록 | 프리즘으로 나눈 빛, 거울, 반투명 거울, 파랑 필터, 유리 블록으로 수정 세 개 켜기 (원래 프로토타입의 방) |
| 5 | 발판과 창살 | 발판, 창살 | 초록빛의 길을 창살이 막고 있습니다. 남는 물체를 발판에 올려 창살을 열어 둡니다 |
| 6 | 빛을 막는 사람 (2인용) | 몸으로 빛 막기 | 다른 광원의 흰빛이 빨강 수정에 섞여 듭니다. 한 사람이 몸으로 흰빛을 막고 있는 동안 다른 사람이 문으로 나가야 합니다 |
| 7 | 문지기 (2인용) | | 거울과 문이 벽 너머에 있습니다. 한 사람이 발판을 밟아 창살을 열어 주면 다른 사람이 들어가 거울을 돌리고 문으로 나갑니다 |
| 8 | 빛의 열쇠 | 감지기 | 반투명 거울로 나눈 빛 하나를 감지기로 보내 창살을 열고, 다른 하나를 빨강 필터를 거쳐 수정으로 |
| 9 | 상자 나르기 | 상자 | 상자 두 개로 하나는 발판을 눌러 창살을 열고, 하나는 초록 수정에 섞여 드는 흰빛을 막습니다 |
| 10 | 건너뛰는 빛 | 순간이동 고리 | 수정이 기둥 벽 너머에 있습니다. 거울 두 개로 빛을 순간이동 고리에 넣으면 벽 너머에서 나와 프리즘에서 갈라집니다. 출구는 아래쪽 벽 |
| 11 | 모든 장치 | | 문 앞을 창살이 막고 있습니다. 감지기, 순간이동 고리, 상자, 반투명 거울을 모두 써서 두 수정을 켜고 나갑니다 |
| 12 | 색 섞기 | 청록·자홍 수정 | 하나뿐인 파랑 빛을 반투명 거울로 나눠 청록(초록 + 파랑)과 자홍(빨강 + 파랑) 수정에 보내고, 모퉁이에 필요한 거울은 아래쪽에서 들고 옵니다 |
| 13 | 높이 넘는 빛 | 낮은 벽, 빛 승강기 | 낮은 벽이 빛길을 막습니다. 빛 승강기를 빛길에 옮겨 빛을 높이 올리면 벽을 넘고, 벽 너머의 승강기가 다시 내린 빛을 거울로 꺾어 흰 수정에 보냅니다 |
| 14 | 건네주기 (나뉜 2인용) | 전달 창구, 연결 색 | 각자의 방에 상대 방의 창살을 여는 발판이 있습니다. 상자 하나는 내 발판에, 하나는 전달 창구로 건네 상대의 발판에 올려야 두 창살이 모두 열립니다 |
| 15 | 빛 넘겨주기 (나뉜 2인용) | | 왼쪽 방의 초록빛이 순간이동 고리로 오른쪽 방에 건너가 수정을 켜고, 오른쪽 방의 감지기가 왼쪽 방의 창살을 엽니다. 서로의 빛이 서로의 문을 엽니다 |
| 16 | 바꿔 쓰기 (나뉜 2인용) | | 왼쪽 방에는 거울이, 오른쪽 방에는 프리즘이 없습니다. 필요한 물체가 상대 방에 있어서 전달 창구로 바꿔 들어야 합니다 |

2인용 방(6, 7, 14~16)은 혼자 할 때 건너뜁니다. 혼자 하면 방 1~5, 8~13의 11개 방을 합니다(혼자 하기 메뉴와 `--level`의 번호는 이 11개 방의 순서입니다). 나뉜 2인용 방에서 호스트는 왼쪽 방에서, 참가자는 오른쪽 방(`start2`)에서 시작합니다.

방 순서를 바꾸면서 방 파일 이름이 바뀌었으므로, 예전 진행 기록(`~/.prism_progress`)은 이름이 바뀐 방부터 다시 쌓입니다.
